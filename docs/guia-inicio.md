# Guía de inicio

La guía de configuración vive **dentro de FARO**: abre la pestaña **Guía** (barra lateral). Allí están el *Setup* paso a paso con el estado de tu configuración, el ejemplo del source de un repositorio ya conectado, las convenciones y la solución de problemas.

El contenido sale de estos archivos del repositorio de FARO, que son la única fuente:

| Archivo | Qué es |
|---|---|
| [`templates/AGENTS.md`](../templates/AGENTS.md) | Plantilla de `AGENTS.md` para un repo nuevo |
| [`templates/docs/_frente/`](../templates/docs/_frente/) | Plantillas de `index.md`, `plan.md` y `progreso.md` |
| [`examples/erp-api/`](../examples/erp-api/) | Ejemplo completo de un repositorio configurado |
| [`docs/convenciones.md`](convenciones.md) | Convenciones (carpeta `docs/`, nombres, decisiones…) |
| [`docs/solucion-problemas.md`](solucion-problemas.md) | Problemas frecuentes |

Referencia técnica del endpoint y del modelo: [`diseno-conexion.md`](diseno-conexion.md).
